## A.5 Printer Adjustments (optional board required)

### A.5 01 Column Width

The operator chooses the column width to be printed. The range of this setting is 22 through 80.

| Choice | Meaning |
|---|---|
| Range | 22 through 80 |

### A.5 02 Lines Per Page

The operator chooses the amount of lines per page. The range of this setting is 20 through 80.

| Choice | Meaning |
|---|---|
| Range | 20 through 80 |

### A.5 03 Pause Every Page

The operator chooses whether the printer pauses at the end of a page. The choices are:

| Choice | Meaning |
|---|---|
| YES | The printer does pause. |
| NO | The printer doesn't pause. |

### A.5 04 Printer Type

The operator selects which kind of printer to use. The choices are Parallel, Serial or ADP.

| Choice | Meaning |
|---|---|
| Parallel | |
| Serial | |
| ADP | |

### A.5 05 Serial Baud Rate

The operator selects which baud rate to use for Serial or ADP communications (bit rate). The choices are 300, 600, 1200, 2400, 4800. or 9600.

| Choice | Meaning |
|---|---|
| 300 | |
| 600 | |
| 1200 | |
| 2400 | |
| 4800 | |
| 9600 | |

### A.5 06 Serial D.T.R. (Data Terminal Ready)

When a Serial Printer is used, this line may be connected to a printer output line signaling that the printer is busy.

| Choice | Meaning |
|---|---|
| Normal | Normal D.T.R. signal goes low to indicate the printer is not ready. |
| Inverted | Inverted D.T.R. (busy) signal goes high to indicate printer is not ready. |
| Ignore | D.T.R. signal is ignored. |

Press the Escape button to return to the Adjustments Menu. Then, either press the Up or Down button to return to a previous Adjustment Menu Group, or press the Escape button again to return to the Main Menu. Once in the Main Menu, either press the Up button to advance to the next menu selection, the Bookkeeping Menu, or press the Down button to to return to a previous Main Menu selection.
