# Bevarat bildmaterial

De tre WebP-bilderna i denna katalog låg tidigare oanvända i `public/assets/figures/`.
De har flyttats hit utan innehållsändring så att originalen finns kvar men inte publiceras
eller räknas in i appens bygg-/cachebudget. Koppla in dem på relevanta sidor först när
deras avsedda användning har fastställts. Bildstorleksläsaren stöder nu även WebP.
