## What
- `public/assets/maps/playfield.png` (1246×2702, 169 KB): the naked drawing `public/assets/figures/7696d0a6-….png` cropped to the playfield frame and upscaled 2×. Generated by scratchpad `pf1.py` (frame detection via line projections, affine remap per manual map).
- `src/data/positions.json` `{ image:{w,h}, pos:{ "kind:id": [{x,y,l}] } }`; `src/lib/data/positions.ts` (`PLAYFIELD`, `positions`, `posKey`, `allPositions`). Kit `loc` untouched.
- `PlayfieldMap.svelte`: four toggle layers sw/lamp/coil/shot held in a `SvelteSet` (URL `layer=sw,lamp` comma list, `all` accepted, default sw,lamp,coil; `id=` bare id resolved against the layers that are on in order, or exact `id=shot:K`), one image, markers per kind (colour + shape, status colours), selected pulses + label, others dim, labels at zoom ≥1.6 when exactly one component layer is on (shot letters are always printed in the marker); selected always labelled. `?calib=1`: drag / arrow-key markers, drafts in localStorage `taf.positions.draft`, Copy JSON → paste into positions.json. Overlay picker + opacity slider shows the original manual scan (`src/data/overlays.json`: sw/lamp/coil scans and shot pages 9/10, positioned so the scan's playfield frame lands on the drawing's frame; computed by frame detection, thresholds 0.5 for the three scans, 0.2 for the thin-lined shot pages). Default overlay follows the first layer that is on.
- Shots: `src/data/shots.ts` (A–S, no I/O, with source PDF page 9/10); positions under `shot:<letter>` seeded by eye from the shot maps' arrow tips (frame detection failed on those thin-lined scans, threshold 0.2 would work if ever redone). Shot card in the aside links the manual page. Embedded in `src/pages/handbook/[section].astro` after page 9 (`e.data.page === 9`, `<PlayfieldMap client:visible layer="shot" />`), md transcriptions untouched. Start page has a `map?layer=shot` quick link.
- `MiniMap.svelte` takes `pos` only; `ComponentCard` passes `positions(kind,id)`. Precache glob narrowed to `playfield.png`; the three scans (`public/assets/maps/{sw,lamp,coil}.png`) are only loaded as calibration overlays, so the `assets/maps` copy step in `scripts/sync-kit.mjs` must stay.
- Tests: `tests/unit/positions.test.ts` (PNG header = image size, one pos per callout, labels match, inside 0..1, every shot placed, no unknown keys); `tests/e2e/smoke.spec.ts` (shot layer count 17, combine sw+shot → URL `layer=sw,shot&id=K`, handbook embed in `#pg-9 .shot-map`).
